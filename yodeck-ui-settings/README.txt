Yodeck UI設定ファイル一覧
=======================

このフォルダのJSONファイルは、Yodeck管理画面の「UI設定」エディタに
手動で貼り付けて使用するファイルです。

使い方
------
1. Yodeck管理画面 → コンテンツ → アプリ（ウィジェット）を開く
2. 対象ウィジェットの編集画面を開く
3. ZIPファイルをアップロード
4. 「UI設定」のエディタに、対応するJSONファイルの内容を貼り付ける
5. 保存

ファイル対応表
--------------
digital-clock.json → デジタル時計ウィジェット
analog-clock.json  → アナログ時計ウィジェット
scroll-text.json   → スクロールテキストウィジェット
wbgt.json          → 暑さ指数（WBGT）ウィジェット
musaigai.json      → 無災害記録表ウィジェット

※ weather-wbgt はYodeck HTTP APIから位置情報を自動取得するため
   UI設定ファイルは不要です。
